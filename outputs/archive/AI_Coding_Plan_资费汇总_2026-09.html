1三分钟结论

2026 年 9 月的真实格局：国际平台靠「订阅制 + 模糊配额」维持溢价，国内平台已全面转向「Token / 积分制」的透明比价。同样花 ¥134（$20），国内方案能买到的折算 Token 量普遍是 Claude Pro 的 3–7 倍。

性价比第一梯队
  • MiniMax Token Plan（¥49）— 6 亿 token/月，折合 ≈¥0.08/百万 token，全平台最低，且不限购、支持全模态。
  • 阿里云百炼 Coding Plan Pro（¥200）— 90,000 次/月 ≈ 30 亿 token，折合 ≈¥0.07/百万 token，但需每日限量抢购、明令禁止 API 调用。
  • 字节火山方舟（¥40 起）— 模型池最全（GLM / DeepSeek / Kimi / MiniMax / 豆包），首两月 2.5 折，折合 ≈¥0.16/百万 token。
  • DeepSeek 官方按量 — 无订阅、缓存命中输入仅 ¥0.025/百万 token，月均 3 亿 token 场景成本约 ¥33。
价格与可用性的三个「坑」
  • 计量单位不可互换。 请求次数 / Credits / 积分 / AFP / Token 是五种不同口径，官方从不公布倍率表。本站所有 Token 数字均为第三方折算估算，只能用于量级对比。
  • 共享额度陷阱。 Claude Pro/Max、ChatGPT Plus/Pro 的额度在聊天与编程之间共享——白天网页端聊得多，晚上 Claude Code 就少。
  • 「无限」不存在。 所有档位都有 5 小时滚动窗口 + 周限 + 月限中的至少两层；Cursor、Copilot、Windsurf 的「Unlimited」均指 Auto/首方模型路由，选前沿模型仍扣额度。
选购决策骨架
  • 要绝对模型质量（复杂重构、大型仓库）→ Claude Max 5×/20×、Codex Pro 20×，接受 ¥672–1,344/月。
  • 要成本效率 → 阿里百炼 Coding Pro、MiniMax、火山方舟、DeepSeek 按量。
  • 要明确禁止 API 的合规环境 / 企业内部 → GitHub Copilot Business/Enterprise、Tabnine、Gemini Code Assist。
  • 要零成本起步 → CodeGeeX、通义灵码、CodeBuddy 个人版、Trae、Cline/Aider（BYOK）、Kimi Adagio。

3Token 换算是怎么算的（方法与局限）

这是本报告最需要说明的部分。各家平台的用量单位完全不统一，无法直接横向比较，因此本节把换算逻辑与已知误差都摊开讲。

本报告的三个换算假设

结果是量级估算，不是精确承诺

假设 1 — 一次请求 ≈ 折算 token。「1,200 次/5h」这类口径，按第三方实测平均每次交互折算 15M–20M token 量级（含上下文重读、工具调用、多轮 agent 循环）。

假设 2 — 积分与 Credits 按各平台官方抵扣系数回推。智谱积分、小米 Credits 均有官方倍率表可倒推；GitHub / Cursor 的 Credits 未公开系数，因此只给 Credit 数不给 token 数。

假设 3 — 汇率 1 USD = 6.72 CNY。取自 2026-09-14 中间价。汇率波动 ±5% 会直接改变国际平台的 ¥ 单价。

为什么不给「官方 token 数」

因为官方基本不公布

Anthropic 明确不公布 Pro / Max 的 token 配额，只说「相对倍数」；OpenAI 只给消息条数区间；Cursor 只给美元额度池。

唯一的例外是 MiniMax、小米 MiMo、DeepSeek 这类原生 Token 制平台，数字来自官方页面，可信度最高。

因此：同阵营内比单价可信，跨阵营比单价只能看量级。

⚠️ 禁止 API 调用的平台

选型前必须确认的红线

据阿里云百炼官方文档原文，Coding Plan 「严禁 API 调用」，仅可在编程工具内交互式使用，违规「可能导致订阅被暂停或 API Key 被封禁」。

智谱、字节方舟、Kimi 等平台也有类似限制。

结论：要做 Agent 后端、批处理、自动化流水线 → 不要买 Coding Plan，应选 DeepSeek 按量或共绩算力这类允许 API 调用的方案。

换算的三个已知误差源
  • 倍率黑箱。同一个套餐里选不同模型，实际可用量可能差 4–10 倍。例如智谱 Pro 用 GLM-5.3-Flash 和用 GLM-5.3，消耗速度完全不同。表中的折算值取的是主力模型混合使用的中间估计。
  • 缓存命中率。编程场景缓存命中率普遍 >90%，而这部分在多数平台的计费规则里按 10% 甚至更低计价。表中单价未按缓存优惠再打折，实际体感单价通常优于表中数字。
  • 时段折扣。至少 7 家国内平台有夜间折扣：百炼 22:00–08:00 五折、小米 0:00–8:00 ×0.8、百度千帆 21:00–08:00 两折、智谱工作日 14–18 点外 50% 抵扣。夜猫子用户实际成本可再降 30–50%。

下单前必查的 5 项
  • 是否禁止 API 调用 —— 决定你能不能自建 workflow。
  • 额度是否与聊天产品共享 —— Claude / ChatGPT 都是共享的。
  • 「Unlimited」的真实边界 —— Cursor / Copilot / Windsurf 的无限量仅指 Auto 或首方模型。
  • 是否有 5 小时滚动窗口 —— 有窗口意味着上午打满要等到下午才能继续。
  • 是否支持退款 —— 绝大多数平台订阅后不支持退款，务必从低档试起。
